## ROLE

Act as a **senior full-stack ERP/POS engineer + SaaS white-label architecture specialist**.

The existing MedCare Pharmacy & Healthcare ERP already has working modules and business logic.

Your task is to fix and upgrade three connected areas:

1. **Logo update system**
2. **WhatsApp bill sharing**
3. **White-label branding synchronization with Business Profile / Store Information**

This is a production-critical upgrade.

**Do NOT break any existing functionality.**

# 4. OLD LOGO CACHE PROBLEM

Pay special attention to browser/CDN/server caching.

If the same filename is reused, browsers may continue showing the old image.

Use an appropriate cache-busting strategy such as:

* versioned asset URL
* updated timestamp
* unique file name
* controlled cache headers

Do not use an unnecessarily aggressive cache policy that damages performance.

# 10. WHATSAPP BILL SHARING — FIX COMPLETELY

The current WhatsApp bill-sharing feature is not working reliably.

Do a complete end-to-end audit.

Trace the complete workflow:

**Generate Invoice → Generate Bill/PDF → Prepare WhatsApp Share → Open WhatsApp → Send**

Identify exactly where the workflow fails.

Possible failure areas to investigate:

* invoice generation
* PDF generation
* file URL
* blob/file handling
* mobile share API
* WhatsApp URL generation
* phone number formatting
* popup blocking
* browser restrictions
* HTTPS requirement
* Android behavior
* iOS Safari behavior
* desktop behavior
* missing invoice data
* invalid customer number
* incorrect encoding
* incorrect MIME type
* expired temporary URLs

Do not assume the problem is only the WhatsApp link.

# 11. WHATSAPP BILL WORKFLOW

The user should be able to:

1. Generate the invoice.
2. Generate the correct bill/PDF.
3. Click **Send via WhatsApp**.
4. Select/use the customer's registered mobile number.
5. Open WhatsApp using the appropriate supported mechanism.
6. Prepare a professional message.
7. Include the bill/invoice in the supported sharing flow.
8. User can review and send it.

The exact implementation must respect WhatsApp/browser/platform limitations.

Do not fake successful delivery.

# 18. ERROR HANDLING

**Customer mobile number is missing.**

Do NOT show generic errors such as:

`Something went wrong.`

when more useful information is available.
